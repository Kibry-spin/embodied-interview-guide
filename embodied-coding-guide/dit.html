01 · ELEVATOR PITCH

先背这一分钟

60 秒回答

DiT，即 Diffusion Transformer，本质是把扩散模型中常用的 U-Net 去噪网络替换为 Transformer。标准图像 DiT 先用冻结 VAE 将图像压缩到 latent space，对 latent 加噪，再像 ViT 一样把带噪 latent patchify 成 token；扩散时间 t 与类别或文本条件 c 被编码后，通过 adaLN-Zero 调制每个 Transformer Block。Block 用 Self-Attention 建模所有 patch 的全局关系，用 FFN 做逐 token 非线性变换，最后将 token unpatchify 为与 latent 同形状的噪声或速度预测。关键是 DiT 只是网络架构：使用 DDPM 时可以预测 ε、x₀ 或 diffusion v；使用 Flow Matching 时同一类 DiT 改为预测概率路径的 velocity。机器人策略里不再 patchify 图像 latent，而是把 action chunk [B,H,Dₐ] 的每个时间步线性投影成 token，再用视觉、语言、本体与触觉作为条件，联合生成整个动作块。

一句话

Diffusion / Flow Matching 规定“老师给什么题和答案”，DiT 规定“学生用什么网络解题”。

最常见误解

FORWARD

训练时直接采样

REVERSE

CONDITION

2×2 latent patch 变成一个 token

05 · ADALN-ZERO

标准 Transformer Block 如何变成 DiT Block

标准 Pre-Norm Transformer

x ← x + MSA(LN(x))
x ← x + MLP(LN(x))
  • 所有样本使用同一组 LayerNorm affine 参数
  • Block 不知道当前噪声等级
  • 需要额外方式注入生成条件

DiT adaLN-Zero

x ← x + gattn·MSA((1+sa)LN(x)+ba)
x ← x + gmlp·MLP((1+sm)LN(x)+bm)
  • shift、scale、gate 都由条件 c 预测
  • 不同 t/类别得到不同调制
  • gate 初始为0，Block 从恒等映射开始
GLOBAL CONDITIONc = t_emb + y_emb[B,D]
MLP → 6D
ATTENTION MODshift₁ / scale₁ / gate₁调制 LN → MSA → residual
FFN MODshift₂ / scale₂ / gate₂调制 LN → MLP → residual
minimal_adaln_zero.py
def modulate(x, shift, scale):
    # x:[B,L,D], shift/scale:[B,D]
    return x * (1 + scale[:, None, :]) + shift[:, None, :]

class DiTBlock(nn.Module):
    def __init__(self, dim, heads, mlp_ratio=4):
        super().__init__()
        self.norm1 = nn.LayerNorm(dim, elementwise_affine=False)
        self.norm2 = nn.LayerNorm(dim, elementwise_affine=False)
        self.attn = MultiHeadAttention(dim, heads)
        self.mlp = FeedForward(dim, int(dim * mlp_ratio))
        self.to_mod = nn.Sequential(nn.SiLU(), nn.Linear(dim, 6 * dim))

        # 使 shift/scale/gate 初始全为 0
        nn.init.zeros_(self.to_mod[-1].weight)
        nn.init.zeros_(self.to_mod[-1].bias)

    def forward(self, x, c):
        sa, sca, ga, sm, scm, gm = self.to_mod(c).chunk(6, dim=-1)

        h = modulate(self.norm1(x), sa, sca)
        attn_out, _ = self.attn(h, h, h)
        x = x + ga[:, None, :] * attn_out

        h = modulate(self.norm2(x), sm, scm)
        x = x + gm[:, None, :] * self.mlp(h)
        return x
NO AFFINE LNLayerNorm 不自己学 γ/β

仿射调制完全由条件网络产生，避免固定 affine 与动态 affine 重复。

GLOBAL CONDITION同一 c 调制所有 token

计算高效，但空间/时间位置之间使用相同调制函数。

IDENTITY INIT初始 residual gate=0

每个 Block 初始近似 x→x，深层 Transformer 从稳定状态开始学习。

t 和任务条件怎样进入 Transformer

TIMESTEP

控制去噪策略

高噪声阶段应建立全局结构，低噪声阶段应修细节；网络必须知道当前阶段。

POSITION

告诉 token 在哪里

图像使用二维位置，动作使用时间步位置；它与 diffusion timestep t 是两个独立概念。

SEMANTIC COND

告诉模型生成什么

类别、文本、视觉、本体、触觉决定样本属于哪一类条件分布。

07 · DDPM TRAINING

训练不是从噪声循环去噪

一次训练迭代只随机抽一个 t，直接构造 xt，调用一次 DiT 并计算监督。

01得到干净数据

图像先经冻结 VAE 得到 z₀；动作策略则直接使用归一化 action chunk。

02随机采样 t 与 ε

每个 batch 样本可使用不同 t；ε 与数据张量同 shape。

03闭式构造 xt

根据 schedule 取 αt、σt，广播后混合 x₀ 和 ε。

04DiT 预测目标

输入 xt、t 和条件 c，一次输出整个 latent 或 action chunk 的预测。

05计算 MSE

ε-pred 比较真实噪声；x₀/v/flow 参数化则换成对应 target。

dit_ddpm_train_step.py
def train_step(images, labels, vae, dit, alpha_bar):
    with torch.no_grad():
        x0 = vae.encode(images).sample()         # [B,C,H,W]

    B = x0.size(0)
    t = torch.randint(0, len(alpha_bar), (B,), device=x0.device)
    eps = torch.randn_like(x0)

    a = alpha_bar[t].sqrt()[:, None, None, None]
    s = (1 - alpha_bar[t]).sqrt()[:, None, None, None]
    x_t = a * x0 + s * eps

    model_out = dit(x_t, t, labels)
    eps_pred = model_out[:, :x0.size(1)]         # learn_sigma 时取前 C 通道
    loss = F.mse_loss(eps_pred, eps)
    return loss
为什么训练便宜、采样贵

训练可一步构造任意 t 的样本并只调用网络一次；生成时 x₀ 未知，只能从噪声开始多次调用 DiT 逐步积分，因此推理步数直接影响延迟。

08 · SAMPLING & CFG

每一步都并行处理全部 token

扩散生成不是像语言模型那样逐 patch 自回归；每个 denoising step 同时更新整张 latent 或整个 action chunk。

STEP TxT ~ N(0,I)纯噪声
DiT →
STEP T−1xT−1出现全局结构
DiT →
STEP …xt不断修正
DiT →
STEP 0x̂₀干净样本
ε̂cfg = ε̂uncond + s(ε̂cond − ε̂uncond)
TRAIN CFG

随机丢弃条件

训练时一部分样本用 null condition，使同一网络学会有条件与无条件预测。

SAMPLE CFG

每步做两种预测

放大条件方向通常增强一致性，但 scale 过大可能损害多样性与稳定性。

SAMPLER

DDPM / DDIM / ODE

不同更新器决定随机性、数值误差和所需步数，但都反复调用同一去噪网络。

机器人策略中的 CFG

动作生成不一定需要图像生成式的大 guidance scale；过强指导可能放大动作幅度或导致不平滑。是否使用应通过任务成功率、动作连续性和安全约束验证。

10 · YOUR CODE LINE

velocity_net(x_t, t, global_cond) 到底做了什么

它不是“根据 t 算一个速度”，而是对带噪动作场做条件化时序建模。

INPUT 01 / x_t
当前带噪 action chunk

每个动作维和每个未来时间步都被扰动；这是网络真正需要更新的状态。

[B,H,Dₐ]
INPUT 02 / t
当前概率路径位置

同一个 x 值在高噪声和低噪声阶段应采取不同去噪策略。

[B] → [B,D]
INPUT 03 / global_cond
从观察提取的任务条件

可包含视觉、本体、语言、目标数量和触觉表征，决定应该生成哪条动作轨迹。

[B,C] or [B,Lc,D]
NETWORK
Action Embed + DiT Blocks

Linear 将动作投影为 tokens；Self-Attention 建模 H 步关系；adaLN/Cross-Attn 注入 t 与条件。

[B,H,D]
OUTPUT / pred
每个动作位置的预测向量

具体语义取决于 loss：可以是 ε、x₀、diffusion v 或 Flow velocity。

[B,H,Dₐ]
minimal_action_dit.py
class ActionDiT(nn.Module):
    def __init__(self, action_dim, cond_dim, model_dim, horizon,
                 depth=8, heads=8):
        super().__init__()
        self.action_in = nn.Linear(action_dim, model_dim)
        self.time_mlp = TimestepEmbedder(model_dim)
        self.cond_proj = nn.Linear(cond_dim, model_dim)
        self.pos = nn.Parameter(torch.zeros(1, horizon, model_dim))
        self.blocks = nn.ModuleList([
            DiTBlock(model_dim, heads) for _ in range(depth)
        ])
        self.final_norm = nn.LayerNorm(model_dim)
        self.action_out = nn.Linear(model_dim, action_dim)

        # 初始预测接近 0，让迭代从稳定状态开始
        nn.init.zeros_(self.action_out.weight)
        nn.init.zeros_(self.action_out.bias)

    def forward(self, x_t, t, global_cond):
        # x_t: [B,H,Da], t:[B], global_cond:[B,C]
        x = self.action_in(x_t) + self.pos[:, :x_t.size(1)]
        c = self.time_mlp(t) + self.cond_proj(global_cond)  # [B,D]
        for block in self.blocks:
            x = block(x, c)                                # [B,H,D]
        return self.action_out(self.final_norm(x))          # [B,H,Da]
pred = self.velocity_net(x_t, t, global_cond)函数名 velocity_net 只是作者声明“输出会按速度场监督”；真正语义由 target 和 loss 决定，不能只看名字。

11 · DITFLOW & FLOW MATCHING

同一个 DiT，换一套路径与监督

xt = (1−t)ε + tx₁，　ut = dxt/dt = x₁−ε
维度DDPM / Diffusion直线 Flow Matching
概率路径xt=αtx₀+σtε，常由噪声调度定义xt=(1−t)ε+tx₁，噪声到数据直线插值
常见 targetε、x₀、diffusion v 或 score路径速度 ut=x₁−ε
网络DiT(xt,t,c)同样可以是 DiT(xt,t,c)
训练回归选择的 diffusion parameterization回归条件向量场，MSE(pred, x₁−ε)

flow_matching_train.py
def flow_matching_loss(action, global_cond, velocity_net):
    # action: x1 [B,H,Da]
    B = action.size(0)
    noise = torch.randn_like(action)             # x0
    t = torch.rand(B, device=action.device)      # [B]
    t3 = t[:, None, None]                        # [B,1,1]

    x_t = (1 - t3) * noise + t3 * action         # [B,H,Da]
    target_velocity = action - noise             # dx_t / dt

    pred = velocity_net(x_t, t, global_cond)     # DiT: [B,H,Da]
    return F.mse_loss(pred, target_velocity)
euler_sample.py
@torch.no_grad()
def sample_actions(velocity_net, shape, global_cond, steps=10):
    x = torch.randn(shape, device=global_cond.device)  # t=0, pure noise
    grid = torch.linspace(0, 1, steps + 1, device=x.device)

    for i in range(steps):
        t = grid[i].expand(shape[0])
        dt = grid[i + 1] - grid[i]
        v = velocity_net(x, t, global_cond)
        x = x + dt * v                              # Euler ODE update
    return x

为什么扩成 [B,1,1]

让每个样本的标量 t 同时广播到 action horizon H 和动作维 Dₐ。

PRED SHAPE

为什么输出与 xt 同形

向量场必须为样本空间中的每个坐标给出瞬时变化方向。

STEPS

为何10步也能采样

直线路径和较平滑动作常允许较粗 ODE 积分，但步数过少仍会产生离散化误差。

DiTFlow 的准确含义

“DiT”描述 Transformer 型速度网络；“Flow”描述训练目标和 ODE 采样。把它称为扩散策略在工程语境中可以理解，但严格说 Flow Matching 不必对应随机扩散过程，它属于更一般的连续概率流框架。

12 · U-NET VS DIT

为什么生成模型逐渐采用 Transformer

14 · INTERVIEW Q&A

必须能够连续追答

Q1：DiT 与普通 Transformer 最大区别是什么？

主体仍是 Pre-Norm Self-Attention + FFN，但输入是带噪连续样本 token；额外接收 diffusion timestep 和生成条件，并通常用 adaLN-Zero 动态调制每个 Block，输出也映射回连续样本空间。

Q2：DiT 为什么不是自回归模型？

Transformer 只是一种并行序列处理架构。DiT 每个 denoising step 同时更新全部 patch/action tokens；它沿 diffusion time 迭代，而不是沿 token position 逐个生成。

Q3：为什么必须输入 t？

不同噪声阶段的最优预测函数不同：高噪声时重建全局结构，低噪声时修正细节。没有 t，同一个网络无法判断当前信噪比和应采取的去噪幅度。

Q4：adaLN-Zero 为什么有效？

条件产生 shift/scale/gate，实现不同 t 和任务的动态调制；gate 与调制层零初始化使每个残差 Block 初始近似恒等映射，深层训练更稳定且几乎不增加 token 级计算。

Q5：为什么 Action DiT 不需要 VAE？

图像 VAE 是为压缩高维像素空间；机器人 action chunk 维度通常较低，可直接归一化并线性投影。若动作极高维或包含复杂手部轨迹，也可研究 learned action latent，但不是必需。

Q6：Flow velocity 与 diffusion v 有什么区别？

Flow velocity 是选定概率路径的 dx/dt；diffusion v-pred 常定义为 αε−σx₀，是用于扩散模型的参数化。两者可能都叫 v，但 target、恢复公式和 sampler 不同。

Q7：为什么一次生成 action chunk 而非单步动作？

能联合建模未来动作相关性、表达多模态轨迹并摊薄推理开销；代价是对新观察的响应变慢，因此需 execution horizon、replanning、temporal ensemble 或 RTC。

Q8：条件用 adaLN 还是 Cross-Attention？

固定长度全局向量适合 adaLN，计算便宜；可变长度图像/语言/tactile tokens 适合 Cross-Attention，保留细粒度信息。实际 VLA 常让 t 用 adaLN、丰富 context 用 Cross-Attention。
