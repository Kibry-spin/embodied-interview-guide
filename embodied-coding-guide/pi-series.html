01 · ELEVATOR PITCH

先背这一段，再补细节

90 秒版本

π0 用预训练 VLM 理解图像和语言，再让独立 action expert 通过 Flow Matching 一次生成连续动作块，解决自回归离散动作难以覆盖高频灵巧控制的问题。π0-FAST 是一条并行路线：先用 DCT 压缩动作时序，再用 BPE 形成短 token 序列，使自回归 VLA 也能学习高频动作。π0.5 面向开放世界泛化，将 FAST 离散预训练、高层子任务预测和连续 Flow 动作执行结合起来，并把本体状态作为离散文本 token 放入前缀。Knowledge Insulation 进一步阻断连续动作损失对 VLM 的反向干扰，实现“VLM 学知识、action expert 学控制”。π0.6 沿用这套混合与层级设计，升级到 Gemma 3 4B、更大的动作专家、更丰富的数据与元数据条件；π*0.6 则在其上加入价值函数和优势条件，通过 RECAP 从自主执行、示范与人工纠错中迭代改进。

版本范围要说准确

截至 2026 年 8 月，官方已经发布 π0.7。本页按面试笔记的指定范围讲到 π0.6 与其 RL 变体 π*0.6，因此面试时不要再把 π0.6 称为“当前最新一代”。

训练

回归速度场

随机采样真实动作块、噪声与时间 τ，让网络预测把当前 noisy chunk 推向数据分布的方向。

推理

从噪声积分到动作

从高斯噪声开始，多步调用 action expert 更新整个动作块；动作 token 之间是双向注意力。

注意论文与 openpi 的时间方向相反

π0 论文写成 τ=0 为噪声、τ=1 为动作；openpi 代码采用扩散领域更常见的 t=1 为噪声、t=0 为动作。公式看起来会反过来，但本质都是学习同一条噪声—动作路径。面试时先声明自己的约定。

Flow Action Expert

  • 连续值不需要逐维分桶
  • 整个 chunk 联合生成，可表达时间相关性
  • 同一观测下可表示多种合理动作
  • 适合最高 50 Hz 的高频灵巧任务

朴素自回归分桶

  • 量化误差随动作维数累积
  • 序列长，逐 token 推理延迟高
  • 高频相邻动作高度相关
  • 容易优化到复制前一 token 的捷径
[图像, 语言] → [机器人状态] → [noisy action chunk]

π0 使用三块 blockwise causal mask：每块内部双向；后块能看前块，前块不能看后块。这样 VLM token 不被新模态反向扰动，状态和观测 KV 又能在多步 Flow 采样中缓存。

COMPUTE

需要多次前向

每个 chunk 需要多步 ODE/Euler 更新，因此必须缩小 action expert 并缓存条件前缀。

CONTROL

反馈仍可能变旧

一次生成很长 chunk 虽然平滑，但全部执行会降低闭环性；工程上通常滚动执行前 K 步再重规划。

WHY DCT

先去掉时间冗余

平滑动作的大部分能量集中在低频，频域系数比逐时刻动作更短、相关性更低。

WHY LOW-FIRST

先预测整体形状

自回归模型先生成决定轨迹轮廓的低频项，再补细节，rollout 更稳定。

WHY BPE

复用语言模型接口

BPE 无损压缩取整后的系数序列，并给出固定词表，容易并入 VLM tokenizer。

面试问题正确回答容易说错
FAST 加速什么？主要缩短动作 token 序列，使 next-token 训练收敛更快；论文报告在 π0 规模上训练最多约快 5 倍。“把 Flow 的 10 次去噪变成 1 次”
DCT 本身是否有损？DCT 可逆；误差主要来自系数缩放后的取整，BPE 对取整序列是无损压缩。“DCT 会直接删除所有高频项”
为什么比普通分桶好？普通方法忽略时间相关性；FAST 先压缩轨迹，再做自回归预测。“只是把分桶数调得更多”
什么时候未必合适？动作含强突变、冲击或精细高频接触时，需要更多频率系数，压缩率和量化精度会受影响。“FAST 在所有任务都严格优于 Flow”
一句话辨析

π0-FAST 不是 π0 的“快速采样器”，而是把连续 action chunk 编码成短离散 token 后，用标准自回归 next-token prediction 生成；它是动作表示路线的切换。

30 秒回答

π₀.₅ 不是把 VLM 最后一个向量交给独立动作 MLP。图像、语言、状态和子任务构成 prefix，带噪 action chunk 构成 suffix；VLM expert 与 action expert 使用各自参数，但动作 token 通过联合注意力读取 prefix 的 K/V，并预测 Flow 速度场。采用 Knowledge Insulation 时，前向条件仍然连通，只阻断连续动作损失回到 VLM 的梯度，VLM 继续由 Web、文本和 FAST token 的交叉熵训练。

为什么不永远这样做

好处是格式接近 VLM 预训练时见过的数字文本；代价是量化误差、token 数较多、相邻状态的连续关系被硬分桶。KI 研究也比较了普通文本、特殊 token 与连续投影三种方案。

正确理解

  • VLM 仍会被 Web、文本和 FAST token 目标更新
  • action expert 仍能通过 attention 读取 VLM 表示
  • 阻断的是连续 Flow loss 对 VLM 的梯度
  • 动作 token 与 Flow action token 互不偷看，避免信息泄漏

常见误解

  • 把 Knowledge Insulation 说成“全程冻结 VLM”
  • 把 VLM 和 action expert 说成完全独立、没有交互
  • 认为只保留 FAST 或只保留 Flow
  • 忽略训练表示与推理表示可以不同

“π0.6 为什么不用前代方案”该怎样纠正

准确说法是：π0.6 仍同时使用 tokenized discrete outputs 与 Flow Matching action chunks，也保留 π0.5 的高层子任务—低层动作层级。它主要减少的是对任务专用后训练的依赖，而不是放弃 FAST、Flow 或层级推理。

30 秒回答

π0.6 的创新重点不在重新定义动作生成，而在把 π0.5 + KI 的混合路线做大做强：升级 Gemma 3 4B 和约 860M 动作专家，使用更高分辨率多相机输入、更丰富的跨平台数据与 metadata 条件，并把去噪控制在 5 步。结果是无需针对每项任务专门后训练，也能获得更强的开箱速度、成功率与泛化。

08 · π*0.6 / RECAP

星号代表从经验中学习

π0.6 是监督训练的基础模型；π*0.6 才是加入优势条件、用 RECAP 做真实机器人 RL 的版本。

π0.6

  • 多源数据监督学习
  • 继承 π0.5 的层级与 KI
  • 输出 FAST token 与 Flow 连续动作
  • 是 π*0.6 的初始化基础

π*0.6

  • 额外输入二值优势指示 I
  • 结合单独训练的多任务价值函数
  • 利用自主 rollout、示范与专家纠错
  • 通过多轮部署—学习继续提升

HETEROGENEOUS DATA

为什么用条件而非筛掉坏数据

示范、旧策略、自主失败和人工纠错都保留；I 告诉模型哪些动作更可能改善结果。

VALUE, NOT DQN

不是 DQN / SAC

RECAP 学的是多任务分布式 V(o,ℓ)，再做优势条件的策略提取；不是用 Q 网络直接 argmax，也不是 SAC 熵正则 actor。

OFFLINE-STYLE RL

为什么适合大型 VLA

不用对 Flow VLA 直接做昂贵且不稳定的 on-policy PPO；可反复利用离线与历史 off-policy 数据。

人类纠错怎样进入 RECAP

机器人自主执行时，专家可以在关键错误处接管并提供正确动作；这些 intervention 强制视为正向样本。价值函数同时从成功/失败结果学习，后续策略再基于二值优势条件吸收这些异构数据。

11 · INTERVIEW DRILLS

按“改了啥—为什么—代价”练回答

先自己讲 60 秒，再展开参考答案。

QUESTION 01

π0 为什么不用普通自回归离散动作？

回答至少包含：高频动作、相邻相关性、量化、chunk、多峰性。

高频控制下动作序列很长、相邻时刻高度相关，逐维逐时刻离散化既有量化误差，也容易让 next-token 训练学成复制上一动作。π0 用 Flow Matching 对整个连续 action chunk 联合建模，能表达时间相关和多种合理轨迹，同时避免把每个连续维度变成大量离散 token。代价是推理要做多次动作专家前向。

QUESTION 02

FAST 为什么 DCT 后还需要 BPE？

区分：DCT、取整、低频优先、BPE 各自负责什么。

DCT 把时间域相关性转成频域稀疏性；缩放取整把连续系数变成整数；低频优先让自回归先决定轨迹轮廓；BPE 再无损合并常见整数片段和大量零附近系数，得到更短、固定词表的动作 token。BPE 不是替代 DCT，两者分别解决连续信号压缩和离散序列压缩。

QUESTION 03

π0.5 相比 π0 最核心的变化是什么？

不要只答“数据更多”，要讲训练表示、层级推理和开放世界目标。

π0.5 将问题从通用低层控制扩展到新环境长任务：预训练时用 FAST 离散动作统一 next-token 学习，后训练加入连续 action expert 以保证实时执行；推理时同一模型先预测高层子任务，再在子任务条件下生成低层连续动作。再配合跨本体、Web、多模态和高层语义数据获得开放世界泛化。

QUESTION 04

π0.5 的 state token 放在哪里，为什么？

对比 π0 的连续 suffix state 与 π0.5 的离散 prefix state。

π0 将连续本体状态线性投影后放在 action-expert suffix；π0.5 将状态离散分桶并作为文本 token 放入包含图像和语言的 VLM prefix。这样高层子任务预测和低层动作生成都可读取状态，也更贴近 VLM 的文本接口。代价是量化误差和更长 token 序列。

QUESTION 05

Knowledge Insulation 与冻结 VLM 有何区别？

回答清楚前向信息流和反向梯度流。

KI 不是冻结整个 VLM。VLM 仍被 Web、文本和 FAST token 的离散目标更新；前向时 action expert 仍通过 attention 读取 VLM 表示。隔离的是连续 Flow action loss 回传到 VLM 的梯度，所以低层运动学习不会覆盖通用语义知识。

QUESTION 06

π0.6 与 π*0.6 是什么关系？

不要把 RECAP 直接写进 π0.6 的监督训练定义。

π0.6 是升级 VLM、动作专家、数据和 metadata 的监督基础模型；π*0.6 是它的 RL 适配版，额外条件于二值 advantage indicator。RECAP 用价值函数评估自主 rollout、示范和人工纠错，再用优势条件训练迭代改进策略，因此星号对应“从经验学习”的能力。

SELF CHECK

五题快速自测

1. π0-FAST 与 π0 最根本的区别是什么？

π0-FAST 是动作表示与解码范式的改变，不是 Flow sampler 的小优化。

2. FAST 中低频系数优先排列的主要原因是？

先确定全局轨迹轮廓通常比先预测细碎高频项更稳定。

3. π0.5 推理中的高层与低层关系是？

同一模型表示文本子任务分布和连续 action chunk 分布。

4. Knowledge Insulation 阻断的是什么？

它是单向信息流与选择性 stop-gradient，而非冻结整网。

5. RECAP 最接近哪种描述？

它能统一利用示范、自主经验、失败和专家干预，不等同于经典 DQN/SAC。
