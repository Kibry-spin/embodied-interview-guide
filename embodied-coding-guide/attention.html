02 · SHAPE CONTRACT

多头注意力的尺寸主线

约定输入 layout 为 batch-first：[B, L, D]，头数为 H，每头维度 Dₕ=D/H。

输入 x[B,L,D]
→
线性投影[B,L,D]
→
拆分 heads[B,H,L,Dₕ]
→
scores[B,H,Lq,Lk]
→
每头输出[B,H,Lq,Dₕ]
→
合并 heads[B,Lq,D]
交互尺寸检查器
最高频错误：直接 view 后忘记 transpose

view(B,L,H,Dh) 后必须交换序列和头维，得到 [B,H,L,Dh]，才能让每个 head 独立计算序列注意力。

03 · MINIMAL IMPLEMENTATION

从零实现 Multi-Head Attention

这里约定布尔 mask 中 True=允许关注，shape 能广播到 [B,H,Lq,Lk]。

minimal_mha.py
import math
import torch
import torch.nn as nn

class MultiHeadAttention(nn.Module):
    def __init__(self, d_model: int, num_heads: int, dropout: float = 0.0):
        super().__init__()
        assert d_model % num_heads == 0
        self.num_heads = num_heads
        self.head_dim = d_model // num_heads

        self.q_proj = nn.Linear(d_model, d_model)
        self.k_proj = nn.Linear(d_model, d_model)
        self.v_proj = nn.Linear(d_model, d_model)
        self.out_proj = nn.Linear(d_model, d_model)
        self.dropout = nn.Dropout(dropout)

    def _split_heads(self, x):
        # [B, L, D] -> [B, H, L, Dh]
        B, L, _ = x.shape
        x = x.view(B, L, self.num_heads, self.head_dim)
        return x.transpose(1, 2)

    def forward(self, query, key, value, mask=None):
        B, Lq, _ = query.shape

        q = self._split_heads(self.q_proj(query))
        k = self._split_heads(self.k_proj(key))
        v = self._split_heads(self.v_proj(value))

        scores = q @ k.transpose(-2, -1)
        scores = scores / math.sqrt(self.head_dim)

        if mask is not None:
            # 约定 True 表示可见；使用有限最小值避免 dtype 问题
            scores = scores.masked_fill(~mask, torch.finfo(scores.dtype).min)

        attn = torch.softmax(scores, dim=-1)
        attn = self.dropout(attn)
        out = attn @ v                       # [B,H,Lq,Dh]

        out = out.transpose(1, 2).contiguous()  # [B,Lq,H,Dh]
        out = out.view(B, Lq, -1)               # [B,Lq,D]
        return self.out_proj(out), attn
WHY SCALE除以 √Dₕ

Dₕ增大时点积方差随之增大，softmax 容易饱和；缩放使其量级更稳定。

WHY CONTIGUOUS转置后整理内存

transpose 只改变 stride；在 view 前调用 contiguous 最直观可靠。

WHY OUT PROJ混合不同 heads

拼接只把各头并排放置；输出投影进一步学习不同子空间的线性组合。

30 秒面试表达

输入先分别线性投影成 Q、K、V，再拆成多个 head。每个 head 计算缩放点积注意力，经过 mask 和 softmax 后对 V 加权；最后把 heads 合并并做输出投影。多头的意义是在不同表示子空间并行建模不同关系。

04 · SELF VS CROSS

代码相同，输入来源不同

不要把 Self-Attention 简化成“Q=K=V 的数值完全相同”：它们来自同一个输入，但经过不同投影层。

Self-Attention

Q=XWQ, K=XWK, V=XWV
  • Q/K/V 的来源都是同一序列 X
  • 用于序列内部元素之间的信息交互
  • Decoder 自回归时通常加 causal mask

Cross-Attention

Q=XqueryWQ, K/V=XcontextWK/V
  • Q 来自待更新序列，K/V 来自条件序列
  • 允许两种模态或 encoder/decoder 交互
  • Lq 与 Lk 可以不同
调用方式
# Self-Attention：同源输入，不同线性投影
self_out, self_map = mha(x, x, x, mask=self_mask)

# Cross-Attention：动作 token 查询视觉 / 语言条件
cross_out, cross_map = mha(
    query=action_tokens,       # [B, La, D]
    key=context_tokens,        # [B, Lc, D]
    value=context_tokens,      # [B, Lc, D]
    mask=cross_mask,
)

05 · MASK SEMANTICS

Mask 先约定语义，再写代码

Padding Mask

屏蔽补齐位置

常见基础 shape 为 [B,Lk]，扩成 [B,1,1,Lk] 后广播给所有 head 和 query。

valid = token_ids != pad_id       # [B,Lk]
mask = valid[:, None, None, :]    # [B,1,1,Lk]
Causal Mask

不能偷看未来

下三角为 True，shape 为 [1,1,L,L]，允许位置 i 只关注 j≤i。

mask = torch.ones(L, L, dtype=torch.bool)
mask = torch.tril(mask)[None, None, :, :]
mask = mask.to(x.device)
全行都被 mask 时，softmax 可能产生 NaN 或无意义的均匀值

真实工程中应保证每个 query 至少有一个有效 key，或在 softmax 后再次清零并重新归一化。面试时主动指出这一边界会加分。

06 · POSITIONAL ENCODING

正弦位置编码从头写

Self-Attention 对输入排列本身不敏感，位置编码负责注入顺序信息。

PE(pos,2i)=sin(pos/100002i/D)
PE(pos,2i+1)=cos(pos/100002i/D)
sinusoidal_pe.py
import math
import torch
import torch.nn as nn

class SinusoidalPE(nn.Module):
    def __init__(self, d_model: int, max_len: int = 5000):
        super().__init__()
        assert d_model % 2 == 0

        position = torch.arange(max_len).float().unsqueeze(1)  # [L,1]
        div_term = torch.exp(
            torch.arange(0, d_model, 2).float()
            * (-math.log(10000.0) / d_model)
        )                                                     # [D/2]

        pe = torch.zeros(max_len, d_model)
        pe[:, 0::2] = torch.sin(position * div_term)
        pe[:, 1::2] = torch.cos(position * div_term)
        self.register_buffer("pe", pe.unsqueeze(0))           # [1,L,D]

    def forward(self, x):
        # x: [B,L,D]；buffer 会随模型迁移 device，但不参与优化
        return x + self.pe[:, :x.size(1)].to(dtype=x.dtype)
FREQUENCY不同维度对应不同频率

低维变化更快，高维变化更慢，使模型同时表示局部与长距离位置关系。

BUFFERregister_buffer

PE 不是可训练参数，但需要保存进 state_dict，并在 .to(device) 时一起迁移。

SLICING只取当前序列长度

预先生成最大长度，forward 时使用 :L，再依靠 batch 维广播。

07 · AUTOREGRESSIVE INFERENCE

KV Cache：缓存过去，当前只算一次

自回归生成第 t 个 token 时，过去 token 的 K/V 不会改变，因此每层只计算新 token 的 K/V，并拼到缓存末尾。

旧缓存K,V [B,H,t−1,Dh]
＋
新 tokenKnew,Vnew [B,H,1,Dh]
→
新缓存[B,H,t,Dh]
→
单步 scores[B,H,1,t]
single_step_with_cache.py
def forward_step(self, x_new, cache=None):
    # x_new: [B,1,D]；以下省略输出投影
    q = self._split_heads(self.q_proj(x_new))  # [B,H,1,Dh]
    k_new = self._split_heads(self.k_proj(x_new))
    v_new = self._split_heads(self.v_proj(x_new))

    if cache is None:
        k, v = k_new, v_new
    else:
        k = torch.cat([cache["k"], k_new], dim=2)
        v = torch.cat([cache["v"], v_new], dim=2)

    scores = q @ k.transpose(-2, -1) / math.sqrt(self.head_dim)
    attn = scores.softmax(dim=-1)
    out = attn @ v                             # [B,H,1,Dh]

    new_cache = {"k": k, "v": v}
    return out, new_cache

不使用 Cache

  • 每一步重新计算整个前缀的 Q/K/V
  • 单步注意力矩阵不断增大
  • 完整逐 token 生成存在大量重复计算

使用 KV Cache

  • 旧 K/V 直接复用，只投影新 token
  • 每层缓存 shape 随序列长度线性增长
  • 以显存换推理速度；训练阶段通常不使用
一句话回答

KV Cache 缓存每层历史 token 的 Key 和 Value；生成新 token 时只计算新增 K/V，并让新 Query 查询完整缓存，从而去掉对历史 K/V 的重复投影，代价是缓存显存随序列长度线性增长。

练习 A · 10 分钟

实现单头 Cross-Attention

输入 q:[B,Lq,D]、context:[B,Lc,D]，返回 [B,Lq,D]。要求包含缩放与可选 mask。

def cross_attention(q, context, mask=None):
    d = q.size(-1)
    scores = q @ context.transpose(-2, -1) / math.sqrt(d)
    if mask is not None:
        scores = scores.masked_fill(~mask, torch.finfo(q.dtype).min)
    weights = scores.softmax(dim=-1)
    return weights @ context
练习 B · 12 分钟

实现 Causal Self-Attention

给定 x:[B,L,D]，构造下三角 mask，保证第 i 个 token 看不到未来位置。

def causal_attention(q, k, v):
    L = q.size(-2)
    mask = torch.tril(
        torch.ones(L, L, dtype=torch.bool, device=q.device)
    )
    scores = q @ k.transpose(-2, -1) / math.sqrt(q.size(-1))
    scores = scores.masked_fill(~mask, torch.finfo(q.dtype).min)
    return scores.softmax(dim=-1) @ v

09 · QUICK CHECK

四题确认是否真的掌握

1. 输入为 [B,L,D]，拆成 H 个 head 后正确 shape 是？

标准计算布局是 [B,H,L,Dh]，让倒数两维完成序列点积。

2. 为什么除以 √Dₕ？

若 q/k 各维方差约为 1，点积方差约为 Dₕ，除以 √Dₕ 后恢复到稳定量级。

3. Cross-Attention 中哪项正确？

Q 决定“查询什么”，K/V 提供被查询的上下文，两个序列长度可以不同。

4. KV Cache 的缓存维度通常是？

每一层分别缓存 K 和 V，常见布局为 [batch, heads, sequence, head_dim]。
