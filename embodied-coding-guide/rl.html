02 · DQN

Forward + TD Loss 最小实现

Q 网络输出所有离散动作的价值 [B,A]；训练时只取数据中实际执行动作对应的 Q。

y = r + γ(1−done) maxa′Qtarget(s′,a′)
L = Huber(Qonline(s,a), y)
minimal_dqn.py
import torch
import torch.nn as nn
import torch.nn.functional as F

class QNetwork(nn.Module):
    def __init__(self, obs_dim, num_actions, hidden=256):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(obs_dim, hidden), nn.ReLU(),
            nn.Linear(hidden, hidden), nn.ReLU(),
            nn.Linear(hidden, num_actions),
        )

    def forward(self, obs):
        return self.net(obs)                         # [B,A]

def dqn_loss(online_q, target_q, batch, gamma=0.99):
    obs, action, reward, next_obs, done = batch

    all_q = online_q(obs)                            # [B,A]
    q_sa = all_q.gather(1, action[:, None]).squeeze(1) # [B]

    with torch.no_grad():
        next_q = target_q(next_obs).max(dim=1).values # [B]
        td_target = reward + gamma * (1.0 - done.float()) * next_q

    return F.smooth_l1_loss(q_sa, td_target)
GATHER取实际动作的 Q

action[:,None] shape 为 [B,1]，在动作维逐行索引，最后 squeeze 为 [B]。

DONE MASK终止状态不 bootstrap

若回合已经终止，未来回报项乘 0，target 只剩即时奖励 r。

NO GRADTarget 是固定监督信号

阻止梯度通过 next Q 回传，否则优化目标会随当前梯度共同移动。

terminated 与时间上限截断 truncated 可能语义不同

理论上的 bootstrap mask 应针对真正终止状态。若只是达到 time limit，很多实现仍允许 bootstrap；面试时可以先说明采用的数据接口约定。

03 · DOUBLE DQN

Online 选动作，Target 算价值

普通 DQN 的 max 同时负责选择和评价，容易放大估计噪声。Double DQN 把两个角色拆开。

a* = argmaxa′Qonline(s′,a′)
y = r + γ(1−done)Qtarget(s′,a*)
double_dqn_target.py
def double_dqn_loss(online_q, target_q, batch, gamma=0.99):
    obs, action, reward, next_obs, done = batch
    q_sa = online_q(obs).gather(1, action[:, None]).squeeze(1)

    with torch.no_grad():
        # 1. online 网络只负责选动作
        next_action = online_q(next_obs).argmax(dim=1, keepdim=True) # [B,1]

        # 2. target 网络评价被选中的动作
        next_q = target_q(next_obs).gather(1, next_action).squeeze(1) # [B]
        td_target = reward + gamma * (1.0 - done.float()) * next_q

    return F.smooth_l1_loss(q_sa, td_target)
一句话区分

DQN 直接取 target 网络输出的最大 Q；Double DQN 用 online 网络的 argmax 选择动作，再从 target 网络取该动作的 Q，从而降低“同一估计误差既影响选择又影响评价”带来的过估计。

05 · REPARAMETERIZATION

把随机性移到输入 ε

直接从参数化分布 z~N(μ,σ) 采样难以对 μ、σ 反传；重参数化写成确定性变换。

ε ~ N(0,I),   z = μ + σ⊙ε

不可导式调用

dist = torch.distributions.Normal(mu, std)
z = dist.sample()   # 样本不保留到参数的路径
  • 随机采样节点截断路径梯度
  • 不适合训练 SAC actor 或 VAE encoder

重参数化采样

dist = torch.distributions.Normal(mu, std)
z = dist.rsample()  # 内部等价于 mu + std * eps
  • 随机性来自与参数无关的 ε
  • z 对 μ、σ 是可微的确定性函数
vae_reparameterize.py
def reparameterize(mu, log_var):
    # log_var 比直接预测方差更容易保证合法范围
    std = torch.exp(0.5 * log_var)
    eps = torch.randn_like(std)
    return mu + std * eps

06 · SAC ACTOR

既追求高 Q，也保留策略熵

连续动作使用 tanh-squashed Gaussian。Actor 最小化 α logπ(a|s) − Q(s,a)：第一项鼓励熵，第二项鼓励高价值动作。

Jπ = Es,ε[ α logπ(a|s) − min(Q₁(s,a),Q₂(s,a)) ]
sac_actor.py
import torch
import torch.nn as nn

LOG_STD_MIN, LOG_STD_MAX = -20.0, 2.0

class GaussianActor(nn.Module):
    def __init__(self, backbone, mean_head, log_std_head):
        super().__init__()
        self.backbone = backbone
        self.mean_head = mean_head
        self.log_std_head = log_std_head

    def sample(self, obs):
        h = self.backbone(obs)
        mean = self.mean_head(h)
        log_std = self.log_std_head(h).clamp(LOG_STD_MIN, LOG_STD_MAX)
        std = log_std.exp()

        dist = torch.distributions.Normal(mean, std)
        pre_tanh = dist.rsample()                   # 可导采样
        action = torch.tanh(pre_tanh)               # 限制到 [-1,1]

        # 变量变换修正：log π(a) = log N(u) - log|da/du|
        log_prob = dist.log_prob(pre_tanh)
        log_prob -= torch.log(1.0 - action.pow(2) + 1e-6)
        log_prob = log_prob.sum(dim=-1, keepdim=True)
        return action, log_prob

def sac_actor_loss(actor, q1, q2, obs, alpha):
    action, log_prob = actor.sample(obs)            # [B,A], [B,1]
    min_q = torch.minimum(q1(obs, action), q2(obs, action))
    return (alpha * log_prob - min_q).mean()
RSAMPLE动作梯度回到 Actor

Q 对 action 的梯度可以沿 action→pre_tanh→μ,σ 回传。

TWIN Q取 min 抑制过估计

两个 critic 中选择较保守估计，减少策略利用单个 Q 的高估误差。

JACOBIANtanh 后修正 log_prob

tanh 改变了概率密度，若不减 Jacobian 项，熵和 loss 都不正确。

不要把 action.detach() 后再送入 Q

Actor 更新依赖 Q 对动作的梯度。Critic 参数可以临时冻结以节省梯度，但从 Q 输出到 action 的计算图必须保留。

08 · QUICK CHECK

五题快速自测

1. Q 网络输出 [B,A]，action 为 [B]，怎样取 Q(s,a)？

需要为 batch 中每一行选择对应动作列。

2. Double DQN 中 next action 由谁选择？

Online 选，Target 评。

3. TD target 为什么放在 no_grad 中？

Bootstrap target 用于监督当前 Q，不应参与本次反向传播。

4. SAC 中为何使用 rsample 而不是 sample？

rsample 使用重参数化技巧保留路径梯度。

5. SAC Actor loss 的正确符号是？

最小化 αlogπ−Q 等价于兼顾最大化 Q 与策略熵。
