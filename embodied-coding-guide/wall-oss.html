01 · ELEVATOR PITCH

面试先讲这一分半

90 秒回答

WALL-OSS-0.5 是自变量机器人开源的约 4B 参数 VLA，基于 Qwen2.5-VL-3B-Instruct，并增加连续 Action Expert。它采用 Mixture-of-Transformers：视觉、语言、本体状态和离散动作由 VL Expert 处理，带噪连续动作由 Action Expert 处理，两条路径通过联合注意力共享上下文。核心是 gradient-bridged co-training：多模态 CE 保留语义与空间理解，离散动作 CE 以语言模型原生的 next-token 形式向骨干提供强动作梯度，连续 Flow Matching 则负责高精度动作生成。离散动作使用视觉对齐的 RVQ tokenizer，但只在训练中充当梯度桥，推理时不解码，真机只执行连续动作。数据上每轮训练覆盖 20 多种本体、超过 100 万条轨迹，并混合约 9000 万条多模态样本，目标是让预训练模型本身具备可测试的零样本行为，而不只是提供微调初始化。

一句话记忆

离散路径负责“教会 VLM 怎么行动”，连续路径负责“把动作精确做出来”。

02 · MOTIVATION

它真正解决什么矛盾

理解这张表，才能回答“为什么不只用离散动作”以及“为什么不只训练 Flow”。

动作路线优点根本问题在 WALL 中的职责
离散 Action Token + CE与 LLM next-token 训练完全同构；梯度强、容易作用到大骨干量化损失、长 token 序列和误差累积，不适合精细真机控制训练桥梁：塑造 action-aware representation
Continuous Flow Matching直接输出连续 action chunk；精度高、能表达多模态动作小 Action Expert 容易吸收损失，传入巨大 VLM 的动作梯度偏弱部署接口：最终真机只执行这条路径
Multimodal CE维持视觉、语言、空间和任务理解本身不能保证动作可执行语义锚点：避免只学动作而丢失具身认知
常见错误

“离散动作更强，所以 WALL 推理时先生成离散动作，再转连续动作”是错的。两种动作 token 在前向传播中相互不可见，推理时离散 token 不被解码；它的价值主要体现在训练梯度。

13 · INTERVIEW Q&A

自变量面试高频追问

Q1：为什么 Flow-only 不能充分训练 VLM？

动作 token 数量少，且 Action Expert 可以在较小参数空间内吸收大部分连续动作损失；传入巨大骨干的梯度弱。离散动作 CE 与 VLM 原生目标同构，能直接迫使视觉语言特征编码动作相关信息。

Q2：为什么不直接执行 RVQ token？

离散化必然引入量化误差，细粒度动作还可能需要较长 token 序列。WALL 利用其强训练梯度，但把精度敏感的执行留给连续 Flow，实现训练效率与控制精度分工。

Q3：两条动作路径会不会互相抄答案？

离散与连续动作 token 在前向 attention 中相互屏蔽，因此不能直接读取对方输出；它们都读取观察条件，Flow 梯度仍能通过共享上下文更新 VL Expert。

Q4：action-space loss 与 velocity loss 有什么关系？

由 Â=Aτ+(1−τ)vθ 可得，clean-action MSE 等价于带 (1−τ)² 权重的 velocity MSE，因此自然强调高噪声阶段的全局轨迹学习。

Q5：如果加入触觉，你会放在哪里？

先按传感器类型编码为 tactile tokens，并与视觉、语言、状态一起作为 Action Expert 的上下文；同时增加接触状态等辅助 CE 构成触觉梯度桥。对高带宽视触觉要控制 token 数与时序对齐，并用随机模态 dropout 保证缺失时可退化运行。

Q6：如何验证触觉真的有效？

固定视觉、动作数据量和训练配置，对比无触觉、触觉 token、触觉辅助损失与完整模型；按接触前后、遮挡程度和物体未见性分组，并评估成功率、动作误差、滑移/数量估计和恢复行为。

Q7：WALL 的零样本能力应该怎么描述？

它证明了跨场景和新物体组合的直接部署潜力，但“未见”仍可能共享预训练技能，且使用人工 milestone 进度而非全部严格成功。应说具有一定零样本泛化，不宜说已经解决开放世界操作。

Q8：你认为下一版最值得改什么？

加入多帧或显式记忆以增强长时域状态估计；把固定26维扩展成分组可组合动作空间；增强高自由度手部和接触数据；建立跨机器人、长周期、严格成功率统一评测。
