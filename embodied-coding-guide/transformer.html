01 · ELEVATOR PITCH

先背这一分钟

60 秒回答

Transformer 用注意力替代循环结构，使同一序列的 token 能并行计算并直接建立全局依赖。原始模型采用 Encoder–Decoder：Encoder Layer 由双向 Self-Attention 和位置前馈网络组成；Decoder Layer 多一个 Cross-Attention，并在 Self-Attention 中加入 causal mask 防止看到未来。每个子层外都有残差、Dropout 和 LayerNorm。输入 token 先经过 Embedding 与位置编码，Decoder 输出再通过线性层映射为词表 logits。训练时对 target 右移，输入 BOS 到倒数第二个 token，标签是第二个 token 到 EOS；推理时只能自回归生成，并用 KV Cache 复用历史 Key/Value。现代 LLM 通常只保留 Decoder，改用 Pre-Norm、RMSNorm、RoPE 和 SwiGLU；VLA 则进一步把图像、语言、本体状态和动作表示成 token 或交给专用 Action Expert。

搭建口诀

先做表示 → Attention 交换信息 → FFN 逐 token 变换 → 残差保信息 → Norm 稳训练 → Mask 限制可见性 → Head 输出任务结果。

02 · ARCHITECTURE FAMILIES

“Transformer”不只一种结构

先判断模型属于哪一类，再讨论 mask、训练目标和推理方式。

架构可见性与模块典型任务具身场景理解
Encoder-only双向 Self-Attention；每个 token 可看完整输入理解、分类、检索、表征学习视觉/状态编码器、融合编码器；不能天然自回归生成
Decoder-onlyCausal Self-Attention；只能看当前位置及过去LLM、VLM、序列生成把图像、语言、状态和离散动作串成序列统一预测
Encoder–DecoderEncoder 双向理解；Decoder 通过 Cross-Attention读取 memory翻译、条件生成、序列到序列观察编码器 + 动作查询/动作解码器，适合异构模态条件生成
BERT-LIKE

Encoder-only

重点是得到上下文化表征，不强调逐 token 生成。

GPT / VLM

Decoder-only

结构统一、扩展简单，是当前语言模型与大量 VLM 的主流。

T5 / ORIGINAL

Encoder–Decoder

条件输入和生成序列职责清晰，Cross-Attention 显式连接两侧。

高频误区

“Decoder-only 没有 Encoder，所以不能看图像”不对。视觉编码器可以先产生 image tokens，再把它们作为前缀 token 或通过 Cross-Attention 提供给语言 Decoder。

04 · TRANSFORMER BLOCK

Attention 通信，FFN 计算

Attention 不承担全部建模能力。大量参数和逐 token 非线性来自 FFN。

组件做什么是否跨 token典型参数量
Multi-Head Attention根据内容动态聚合其他 token是Q/K/V/O 约 4D²
Position-wise FFN对每个位置执行相同的非线性通道映射否约 2DDff；若 Dff=4D，则约 8D²
Residual保留恒等路径，改善深层梯度传播否无参数
LayerNorm / RMSNorm稳定激活尺度和训练只沿特征维每层 O(D)
FFN(x) = W₂·σ(W₁x+b₁)+b₂
feed_forward.py
import torch.nn as nn

class FeedForward(nn.Module):
    def __init__(self, d_model, d_ff, dropout=0.1):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(d_model, d_ff),
            nn.GELU(),
            nn.Dropout(dropout),
            nn.Linear(d_ff, d_model),
        )

    def forward(self, x):
        # [B,L,D] -> [B,L,Dff] -> [B,L,D]
        return self.net(x)
SAME WEIGHTS位置之间共享 FFN

对所有 token 使用同一组线性层，但每层 Transformer Block 的 FFN 参数不同。

CHANNEL MIXER只混合特征维

FFN 不改变序列长度，也不让不同位置直接通信。

PARAMETER HEAVY常占大量参数

Dff 通常大于 D，因此不能把 Transformer 简化成“只有 Attention”。

05 · RESIDUAL & NORMALIZATION

原论文是 Post-Norm，现代大模型多用 Pre-Norm

Post-Norm · 原始 Transformer

y = LN(x + Sublayer(x))
  • 先计算子层与残差，再做归一化
  • 与原论文结构图一致
  • 模型很深时，恒等梯度路径会经过 LayerNorm，优化更敏感

Pre-Norm · 常见现代实现

y = x + Sublayer(LN(x))
  • 残差主干保持直接恒等路径
  • 深层网络通常更容易训练
  • 堆叠末尾通常再加一次 final norm
LayerNorm(x) = γ · (x−μ) / √(σ²+ε) + β对每个 token 的最后一个特征维 D 求均值与方差，不依赖 batch 内其他样本。
方法以 x:[B,L,D] 为例统计什么是否依赖 batch训练/推理差异适用判断
BatchNorm序列写法需指定通道布局；CNN 常对每个 channel 跨 N/H/W 统计依赖；小 batch 或不同设备局部统计可能不稳训练用当前 batch，推理用 running mean/var适合卷积视觉骨干；不自然适配变长 token 和自回归。
LayerNorm每个 token 独立沿最后一维 D 求均值和方差不依赖训练与推理使用当前 token 自身统计Transformer 的经典选择，中心化并缩放。
RMSNorm每个 token 沿 D 只计算均方根，不减均值不依赖训练与推理一致省去中心化，现代 LLM 常用；不等于 BatchNorm 的简化版。
RMSNorm(x) = γ · x / √(mean(x²)+ε)只做尺度归一化，不减去 μ；常见实现只有缩放参数，没有独立偏置 β。
为什么 Transformer 少用 BatchNorm

序列长度、padding 和 batch 大小都可能变化，自回归解码甚至一次只有一个新 token；BN 的跨样本统计会让输出依赖同 batch 其他样本，并产生 train/eval 两套统计。LN/RMSNorm 对每个 token 独立，更契合序列模型。

Pre-Norm 与 RMSNorm 是一回事吗？

不是。Pre/Post 描述 Norm 放在子层前还是残差相加后；LN/RMSNorm 描述归一化算子本身。可以组合成 Pre-LN、Pre-RMSNorm 等结构。

06 · ENCODER LAYER

两条子层：Self-Attention + FFN

INPUTx [B,S,D]源序列表示
→
SUBLAYER 1Bidirectional Self-AttentionQ=K=V 来源相同
→
SUBLAYER 2Position-wise FFN每个位置独立
→
OUTPUTmemory [B,S,D]供 Decoder 查询
pre_norm_encoder.py
class EncoderBlock(nn.Module):
    def __init__(self, d_model, n_heads, d_ff, dropout=0.1):
        super().__init__()
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.attn = MultiHeadAttention(d_model, n_heads, dropout)
        self.ffn = FeedForward(d_model, d_ff, dropout)
        self.drop = nn.Dropout(dropout)

    def forward(self, x, src_mask=None):
        # Pre-Norm：Norm -> Sublayer -> Dropout -> Residual
        h = self.norm1(x)
        attn_out, _ = self.attn(h, h, h, mask=src_mask)
        x = x + self.drop(attn_out)
        x = x + self.drop(self.ffn(self.norm2(x)))
        return x
为什么 Encoder 不需要 causal mask？

Encoder 的目标是理解完整条件输入，不承担“不能偷看未来”的自回归生成约束，因此通常允许所有有效源 token 双向交互，只屏蔽 padding 或任务指定的不可见区域。

07 · DECODER LAYER

多一条 Cross-Attention，职责完全不同

TARGETy [B,T,D]已知目标前缀
→
SUBLAYER 1Causal Self-AttentionQ/K/V 来自目标侧
→
SUBLAYER 2Cross-AttentionQ 来自目标；K/V 来自 memory
→
SUBLAYER 3FFN逐 token 非线性变换
pre_norm_decoder.py
class DecoderBlock(nn.Module):
    def __init__(self, d_model, n_heads, d_ff, dropout=0.1):
        super().__init__()
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.norm3 = nn.LayerNorm(d_model)
        self.self_attn = MultiHeadAttention(d_model, n_heads, dropout)
        self.cross_attn = MultiHeadAttention(d_model, n_heads, dropout)
        self.ffn = FeedForward(d_model, d_ff, dropout)
        self.drop = nn.Dropout(dropout)

    def forward(self, y, memory, tgt_mask=None, memory_mask=None):
        h = self.norm1(y)
        out, _ = self.self_attn(h, h, h, mask=tgt_mask)
        y = y + self.drop(out)

        # Query 长度 T；Key/Value 长度 S，可以不相等
        q = self.norm2(y)
        out, _ = self.cross_attn(q, memory, memory, mask=memory_mask)
        y = y + self.drop(out)

        y = y + self.drop(self.ffn(self.norm3(y)))
        return y
注意力QK / VScores作用
Decoder Self-Attention[B,H,T,Dh][B,H,T,Dh][B,H,T,T]读取目标前缀，必须 causal
Cross-Attention[B,H,T,Dh][B,H,S,Dh][B,H,T,S]每个目标位置查询完整源条件

08 · MASK CONTRACT

按“作用位置”和“功能”分别记

Mask 最容易错的不是下三角，而是不同接口中 True 的含义可能相反。

名称作用位置典型 shape屏蔽什么
src_maskEncoder Self-Attention[B,1,1,S]源序列的 PAD key
tgt_maskDecoder Self-Attention[B,1,T,T]目标 PAD key + 未来 token
memory_maskDecoder Cross-Attention[B,1,1,S] → 广播到 TEncoder memory 中的源 PAD
make_masks.py
def make_masks(src_ids, tgt_ids, pad_id):
    # 本页手写 MHA 约定：True = 允许关注
    src_valid = src_ids.ne(pad_id)              # [B,S]
    tgt_valid = tgt_ids.ne(pad_id)              # [B,T]

    src_mask = src_valid[:, None, None, :]       # [B,1,1,S]
    memory_mask = src_mask                       # 广播到 [B,H,T,S]

    T = tgt_ids.size(1)
    causal = torch.tril(torch.ones(
        T, T, dtype=torch.bool, device=tgt_ids.device
    ))                                           # [T,T]
    tgt_mask = (
        tgt_valid[:, None, None, :]              # key padding
        & causal[None, None, :, :]               # no future
    )                                            # [B,1,T,T]
    return src_mask, tgt_mask, memory_mask
WHY MASK K

Padding 通常屏蔽 Key 列

不让任何 query 从 PAD value 聚合信息；PAD query 的输出可在后续清零或被 loss 忽略。

CAUSAL

下三角表示过去可见

第 i 行只允许关注 j≤i，训练时所有位置仍可并行计算。

API WARNING

True 语义不统一

自写代码、SDPA、nn.Transformer 的布尔 mask 约定可能不同，调用前必须查接口。

全行被屏蔽

如果一个 query 没有任何有效 key，softmax 可能产生 NaN 或无意义结果。应保证至少一个可见位置，或在 softmax 后清零并安全归一化。

09 · MINIMAL FULL MODEL

把各组件拼成 Encoder–Decoder

以下代码省略 tokenizer 和采样策略，MHA、FFN 与 Block 使用前文实现。

minimal_transformer.py
class Transformer(nn.Module):
    def __init__(self, src_vocab, tgt_vocab, d_model=512,
                 n_heads=8, n_layers=6, d_ff=2048,
                 max_len=2048, dropout=0.1):
        super().__init__()
        self.d_model = d_model
        self.src_emb = nn.Embedding(src_vocab, d_model)
        self.tgt_emb = nn.Embedding(tgt_vocab, d_model)
        self.pos = SinusoidalPE(d_model, max_len)
        self.drop = nn.Dropout(dropout)

        self.encoder = nn.ModuleList([
            EncoderBlock(d_model, n_heads, d_ff, dropout)
            for _ in range(n_layers)
        ])
        self.decoder = nn.ModuleList([
            DecoderBlock(d_model, n_heads, d_ff, dropout)
            for _ in range(n_layers)
        ])
        self.enc_norm = nn.LayerNorm(d_model)
        self.dec_norm = nn.LayerNorm(d_model)
        self.lm_head = nn.Linear(d_model, tgt_vocab, bias=False)

    def encode(self, src_ids, src_mask):
        x = self.src_emb(src_ids) * math.sqrt(self.d_model)
        x = self.drop(self.pos(x))
        for block in self.encoder:
            x = block(x, src_mask)
        return self.enc_norm(x)

    def decode(self, tgt_ids, memory, tgt_mask, memory_mask):
        y = self.tgt_emb(tgt_ids) * math.sqrt(self.d_model)
        y = self.drop(self.pos(y))
        for block in self.decoder:
            y = block(y, memory, tgt_mask, memory_mask)
        return self.lm_head(self.dec_norm(y))

    def forward(self, src_ids, tgt_ids,
                src_mask, tgt_mask, memory_mask):
        memory = self.encode(src_ids, src_mask)
        return self.decode(tgt_ids, memory, tgt_mask, memory_mask)
代码接口提醒

SinusoidalPE 如果内部已经乘过 √D，外面就不能再乘一次。本页选择职责更清晰的写法：Embedding 缩放在模型中完成，PE 类只负责相加。

参数主线

每个 Encoder 有 1 个 MHA + 1 个 FFN；每个 Decoder 有 2 个 MHA + 1 个 FFN。层数 N 增加时，注意参数不是共享的。

10 · TRAINING VS INFERENCE

训练并行，生成串行

Causal mask 不会让训练变成 for-loop；已知完整标签时，所有目标位置可以一次性预测。

训练 · Teacher Forcing

  • 输入：[BOS, y₁, y₂, …, yₙ₋₁]
  • 标签：[y₁, y₂, …, yₙ, EOS]
  • 一次 forward 得到所有位置 logits
  • PAD 使用 ignore_index 排除 loss

推理 · Autoregressive

  • 开始只有 BOS，每次生成一个新 token
  • 新 token 追加到前缀，直到 EOS 或最大长度
  • Encoder memory 只计算一次
  • Decoder 用 KV Cache 避免重复投影历史 K/V
teacher_forcing.py
# tgt: [BOS, y1, y2, ..., EOS, PAD, ...]
tgt_in = tgt[:, :-1]                          # [B,T-1]
labels = tgt[:, 1:]                           # [B,T-1]

src_mask, tgt_mask, memory_mask = make_masks(
    src, tgt_in, pad_id
)
logits = model(src, tgt_in, src_mask, tgt_mask, memory_mask)

loss = F.cross_entropy(
    logits.reshape(-1, logits.size(-1)),
    labels.reshape(-1),
    ignore_index=pad_id,
)
greedy_decode_concept.py
@torch.no_grad()
def greedy_decode(model, src, src_mask, bos_id, eos_id, pad_id, max_len):
    memory = model.encode(src, src_mask)       # 只算一次
    ys = torch.full((src.size(0), 1), bos_id, device=src.device)

    for _ in range(max_len - 1):
        _, tgt_mask, memory_mask = make_masks(src, ys, pad_id)
        logits = model.decode(ys, memory, tgt_mask, memory_mask)
        next_id = logits[:, -1].argmax(dim=-1, keepdim=True)
        ys = torch.cat([ys, next_id], dim=1)
        if torch.all(next_id.squeeze(-1).eq(eos_id)):
            break
    return ys

# 清晰版会重复计算 Decoder 前缀；生产实现需为每层维护 KV Cache。

11 · DISTRIBUTED TRAINING & ETA

先算 step，再解释为什么没有线性加速

“训练多久”必须同时给模型、数据、分辨率/序列、全局 batch、更新步数、硬件和并行策略。

Bglobal = Bgpu × gradient accumulation × world size
optimizer steps / epoch = ceil(Nsamples / Bglobal)
训练墙钟时间 ≈ optimizer steps × 平均 step time + eval / checkpoint / restart吞吐最好同时报告 samples/s 或 tokens/s；只报“训练两天”无法比较。
策略每张卡放什么主要通信解决的问题代价/陷阱
DDP完整模型、梯度和优化器状态梯度 All-Reduce模型能单卡放下时扩大全局吞吐显存不随卡数明显下降；小 batch、慢数据或通信会降低效率。
FSDP / ZeRO分片参数、梯度和/或优化器状态按层 All-Gather、Reduce-Scatter单卡放不下大 VLM/VLA通信更频繁；wrap 粒度、prefetch 和 checkpoint 保存方式影响很大。
Tensor Parallel单层矩阵按维度切分层内集合通信单层或模型宽度过大强依赖高速互联，跨节点代价高。
Pipeline Parallel不同层放不同设备阶段间激活传输模型深且可分阶段micro-batch 不足会产生 pipeline bubble。
COMPUTE

GPU 没吃满

检查图像解码、DataLoader、CPU→GPU copy、动态 shape、频繁日志和小 kernel，而不是先加卡。

COMMUNICATION

卡越多越慢

记录 All-Reduce/All-Gather 占比、跨节点带宽和 straggler；增加 world size 会减少单卡计算，通信却不同比例减少。

MEMORY

OOM 先拆构成

参数、梯度、优化器、激活、视觉 token 和临时 buffer 来源不同；AMP、checkpointing、FSDP 各解决不同部分。

扩展效率怎么算

speedup(N)=T₁/Tₙ，efficiency=speedup/N。例如 8 卡只快 6 倍，扩展效率是 75%。必须确保比较时全局 batch、训练步数和数值配方可比。

贴合你的回答边界

可以强调自己能把 QTac/策略训练做成配置化、混合精度、断点恢复和固定评测，并理解 DDP/FSDP 的适用条件；如果没有亲自完成大规模多节点预训练，就不要把单机训练包装成分布式经验。

它仍计算精确注意力，主要通过分块和算子融合减少显存中间结果及 HBM 访问；时间复杂度量级仍是 O(L²)，但实际速度和显存显著改善。

14 · HIGH-FREQUENCY QUESTIONS

面试官通常从这里追问

Q1：为什么除以 √dₖ？

若 q、k 各维独立且方差约为1，点积方差随 dₖ 增长。除以 √dₖ 将方差拉回稳定量级，避免 softmax 饱和导致梯度过小。

Q2：为什么多头不是直接切原始 embedding？

实现通常先用 D×D 线性层一次性生成全部 heads，再 reshape；每个 head 的特征都来自原始 D 维的学习投影，而非机械截取一段原向量。

Q3：Attention 与 FFN 分别做什么？

Attention 是 token mixer，让不同位置交换信息；FFN 是 channel mixer，对每个位置独立进行更高维非线性变换。两者缺一都会显著限制表达能力。

Q4：训练时为什么能并行预测全部目标 token？

完整标签已知，通过右移输入和 causal mask，位置 i 只能读取真实前缀，但所有 i 的矩阵计算可一次完成。推理时后续 token 尚不存在，所以必须逐步生成。

Q5：KV Cache 缓存什么？

缓存每层历史 token 的 K/V，而不是注意力矩阵，也通常不缓存 Q。新一步只计算新 token 的 Q/K/V，新 Q 查询历史与新增 K/V。

Q6：Cross-Attention 为什么 Q 与 K/V 长度可不同？

Q 对应要更新的目标位置 T，K/V 对应条件 memory 长度 S，scores 自然是 T×S；注意力要求的是 Q/K 的 head_dim 相同，而不是序列长度相同。

Q7：Pre-Norm 为什么更好训练？

残差主干保留近似恒等的直接梯度路径，梯度不必在每个 Block 后穿过 LayerNorm；深层堆叠通常更稳定，但最终需配合 final norm。

Q8：VLA 为什么不一定用自回归动作 token？

离散 token 易融入 VLM，却有量化与逐 token 延迟；ACT、Diffusion、Flow 可一次生成连续 action chunk。现代 VLA 常让 Transformer 做条件融合，再由连续动作头负责执行。

15 · CLOSED-BOOK PRACTICE

按 15 → 30 → 45 分钟练三档

LEVEL 1 · 15 MIN

EncoderBlock

从零写 Pre-Norm Encoder Layer，包含 MHA、FFN、两次残差、Dropout 和 src mask。

检查：Norm 在子层前；Q/K/V 同源；输出 shape 不变；Dropout 在加残差前；mask 能广播至 scores。

LEVEL 2 · 30 MIN

DecoderBlock + Masks

写 causal self-attention、cross-attention，并构造 tgt padding + causal 联合 mask。

检查：Cross 的 Q 来自目标，K/V 来自 memory；tgt mask 为 [B,1,T,T]；memory mask 屏蔽源 PAD。

LEVEL 3 · 45 MIN

训练与 Greedy Decode

完成 target shift、CE ignore PAD、Encoder 只算一次的 greedy decode，并口述如何加入 KV Cache。

检查：输入 tgt[:-1]、标签 tgt[1:]；logits/label 展平对齐；eval/no_grad；EOS 退出；KV Cache 按 layer 保存。

1. Encoder–Decoder Cross-Attention 的 K/V 来自哪里？

答案：K/V 来自 Encoder memory，Q 来自 Decoder 当前表示。

2. Teacher Forcing 的正确输入与标签关系是？

答案：tgt_in=tgt[:,:-1]，labels=tgt[:,1:]。

3. 下列哪项不会跨 token 交换信息？

答案：FFN 对每个位置独立使用相同参数，只混合通道维。

4. Pre-Norm 的正确结构是？

答案：Pre-Norm 在进入子层前归一化，残差主干直接相加。
