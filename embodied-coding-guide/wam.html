From Reactive Policy to Predictive Control

WAM
先理解未来
再生成动作

World Action Model 把“世界怎样变化”与“机器人该怎样动”放进同一学习系统。它可能显式生成未来视频，也可能只预测未来视觉特征，甚至只在训练时用未来预测塑造表示；真正的共同点是让动作学习获得时序动力学监督。

01 · ELEVATOR PITCH

面试先答这一分钟

60 秒回答

WAM 是 World Action Model。标准 VLA 通常直接建模 p(A|o,l)，依靠 VLM 的语义先验从当前观测和语言生成动作；World Model 建模 p(o′|o,A)，回答执行动作后世界怎样变化；WAM 把未来预测与动作生成连接起来，例如联合建模 p(A,o′|o,l)，或先预测未来视觉状态再通过 inverse dynamics/action expert 得到动作。它的动机是利用视频提供比低维动作更密集的时序监督，并把动力学先验暴露给策略。WAM 不等于“部署时先生成完整视频”：DreamZero 联合生成视频和动作，LaWAM 只预测一次 latent visual subgoal，Fast-WAM 更表明训练期 video co-training 可能比测试期显式想象更关键。工程上 WAM 的主要矛盾是动态泛化与推理延迟之间的权衡。

一句话

VLA 更擅长理解“要做什么”，WAM 重点补充“世界将怎样变化”；实际强模型正在把两者融合，而不是二选一。

02 · THREE DEFINITIONS

先用条件分布区分三个概念

这是后面所有论文的共同坐标系。

VLA · POLICY

当前 → 动作

p(A | o, l)

从图像、语言和本体状态直接生成 action chunk。动力学知识可能隐含在参数中，但通常没有可查询的未来状态接口。

WORLD MODEL · DYNAMICS

当前 + 动作 → 未来

p(o′ | o, A)

给定当前状态与候选动作，预测后续图像、latent state、点轨迹、3D 状态或奖励。它本身不一定能输出可执行动作。

WAM · JOINT INTERFACE

未来 ↔ 动作

p(A, o′ | o, l)

让未来建模与动作解码共享表示、注意力或训练目标，从预测的世界演化中产生机器人动作。

p(A,o′|o,l) = p(o′|o,l) · p(A|o,o′,l)　　或　　p(A|o,l,φ(o′))
World Model 和 WAM 的差别？

World Model 只要能预测转移就成立；WAM 必须再把世界预测与可执行动作建立接口。只有视频生成器而没有动作映射，不是完整机器人策略。

WAM 和 Model-Based RL 一样吗？

不完全一样。经典 MBRL 常在 learned dynamics 中 rollout 候选动作并按 reward/value 规划；许多现代 WAM 直接用监督学习或 Flow Matching 输出 action chunk，并不进行显式 MPC。

Future token 就等于 WAM 吗？

不能只看名字。要检查 future token 是否由可监督的未来状态/特征产生、是否表示 action-conditioned dynamics、推理时怎样影响动作，而不是普通 learnable query。

WAM 一定预测 RGB 吗？

不一定。未来可以是像素视频、VAE latent、DINO feature、object slot、3D 几何、触觉状态或多个模态的联合状态。

03 · WHY WAM

为什么仅做 observation-to-action 还不够

01 · DENSE SUPERVISION视频监督更密集

一个动作向量只有少量关节/位姿数字，未来帧或未来特征包含物体运动、接触、遮挡与场景进度等大量监督。

02 · DYNAMICS PRIOR显式时序先验

静态图文预训练擅长语义识别，视频预训练更直接暴露“什么会动、如何交互、状态怎样连续变化”。

03 · ACTION-FREE VIDEO利用无动作标签视频

通过 latent action / inverse dynamics 学习转移变量，可从机器人或人类视频获得动力学先验，再用少量带动作数据完成 grounding。

04 · CROSS EMBODIMENT视觉结果跨本体共享

不同机器人动作坐标不同，但“杯子被拿起”“抽屉被拉开”等视觉变化具有可迁移性；世界表示可作为中间接口。

05 · QUERYABLE FUTURE未来可以被检查

若模型保留 forward dynamics，可比较候选动作的结果、发现预测—观测偏差并触发重规划。

06 · GENERALIZATION强调物理变化而非背景

理想情况下，视频动力学目标促使模型关注运动和交互，而不是仅记住训练场景纹理；但这必须通过消融和扰动测试证明。

不要过度宣称

“视频模型理解真实物理”不是自动成立的。生成清晰、看似合理的视频，不代表动作可执行、接触力正确或长期动力学一致；WAM 的收益必须与 action-only、无 world loss、无 future conditioning 等基线对照。

06 · TRAINING OBJECTIVES

World loss 与 Action loss 怎样协同

L = λworldLfuture + λactionLaction + λalignLalignment + λregLregularization
WORLD

未来预测

像素噪声/速度 MSE、latent feature MSE、mask/slot/geometry prediction。目标是让表示包含任务相关的时序变化。

ACTION

动作生成

连续动作 L1、Diffusion ε/v、Flow velocity 或离散 action-token CE。最终要对接真实控制空间。

ALIGNMENT

世界—动作对齐

latent-action distillation、inverse dynamics、共享注意力、对比学习或跨模态一致性，防止 world branch 与 action branch 各学各的。

# 概念版 joint video-action flow matching
t_v, t_a = sample_video_time(), sample_action_time()
xv_t = interpolate(video_noise, future_video, t_v)
xa_t = interpolate(action_noise, action_chunk, t_a)

v_video, v_action = wam(xv_t, xa_t, t_v, t_a, current_obs, language)
loss = mse(v_video, target_video_velocity) \
     + lambda_action * masked_mse(v_action, target_action_velocity)
两个时间变量的意义

联合生成模型可能为视频和动作各设一个 noise clock：把动作 clock 从噪声推到数据、保持 world clock 在高噪声，可得到 action policy；给定 clean action 再去噪 world，可近似 forward dynamics；两者都去噪则得到联合未来。这是统一模型支持多种条件查询的一种实现方式，不是所有 WAM 都采用。

07 · INFERENCE MODES

“想象未来”有四种部署含义

面试必须把训练期 world supervision 与测试期 future generation 分开。

EXPLICIT FUTURE

生成未来视频

可视化最直观，也能交给 IDM 或 verifier；但多步扩散和高维像素生成使延迟最大。

LATENT FUTURE

生成未来特征

像 LaWAM 一次得到 latent visual subgoal，再让 Action DiT 条件化去噪，兼顾 foresight 与速度。

DIRECT POLICY

训练想象，推理直出

Fast-WAM 类方法保留 video co-training 获得的动态表示，部署跳过 future generation。

PLAN / VERIFY

候选动作内部 rollout

为多个 action chunk 预测后果，按 reward、task progress、碰撞或触觉风险选动作；计算最贵，但最接近显式规划。

高频错误

不要把“WAM”固定解释成“先生成完整视频再执行”。Fast-WAM 的受控实验指出，强性能主要来自训练期 video co-training，而测试期显式 future imagination 的额外收益相对有限；LaWAM 则保留了测试期 latent future，但避免像素生成。

推荐回答：“WAM 比 VLA 更强吗？”

不能一概而论。WAM 的视频动力学预训练在视觉扰动和新运动泛化上表现出优势，但显式未来生成会显著增加延迟；强 VLA 在语义与某些综合基准上仍可达到或超过 WAM。更重要的是控制数据、模型规模、动作头和评测协议必须匹配。当前趋势是混合系统：VLM/VLA 提供语义规划，world branch 提供动态 foresight，Action Expert 负责连续控制。

09 · LAWAM DEEP DIVE

LaWAM：不生成像素的 latent future

这是与你已有部署经历最直接相关的重点。

核心动机

像素级未来包含大量背景和纹理冗余，而且多步去噪很慢；控制真正需要的是“这个 action chunk 应把场景推进到什么视觉状态”。LaWAM 因此在冻结视觉编码器的 feature space 预测一个 chunk-level latent visual subgoal。

STAGE 1 · LATENT WORLD MODEL

先从无动作标签视频学习转移

FROZEN ENCODERu=f(o), uT=f(oT)DINO-style visual features
→
LATENT IDMz ~ qφ(z|u,uT)transition / latent action
→
LaWM DECODERũT=Fω(u,z)predict future feature
LLAM = ‖ũT−uT‖² + ‖g(s,z)−sT‖² + β KL(qφ || N(0,I))

Inverse encoder 从当前—未来 feature 对中抽取 latent action；forward decoder 根据当前 feature 与 latent action 重建未来 feature。辅助末端状态预测迫使 z 编码真实运动，而不只是画面变化。预训练完成后，decoder 被保留为 LaWM。

STAGE 2 · POLICY INTEGRATION

再让策略自己预测 z，并生成真实动作

POLICY PRIORẑ = pθ(o,l)distill latent action
→
LaWMûT=Fω(u,ẑ)one-pass latent subgoal
→
ALTERNATE-DiTA ~ pη(·|semantic,dynamics)flow-matching action chunk
LLaWAM = λdistill‖ẑ−z‖² + λwm‖ûT−uT‖² + Laction-flow
为什么部署时不能用 q(z|u,uT)？

它需要真实未来 uT，部署时不存在。因此第二阶段训练 policy prior 只根据当前观测与语言预测 ẑ，再由 LaWM 展开成未来 subgoal。

为什么不直接把 z 给动作头？

z 是紧凑 transition code；将其通过 LaWM 展开为具有空间结构的未来视觉特征，能为 action expert 提供“哪里会变化、目标状态是什么”的 richer dynamics context。

Alternate-DiT 做什么？

一条流读取 VLM 语义上下文，另一条流读取当前—未来 latent dynamics，上下文交替进入 action denoising，使“要做什么”和“场景怎样变化”共同约束动作。

Knowledge Insulation 的作用？

阻止 action-expert 梯度破坏已学到的 LaWM 动力学表示，缓解联合训练时 world branch 被动作 loss 覆盖。

论文报告数值怎样正确表述

LaWAM ≠ LaWM

LaWM 是 latent-action-conditioned Latent World Model，即预测 future feature 的 decoder；LaWAM 是完整机器人策略，包含 policy prior、LaWM、VLM 语义流和 Action Expert。另有同名缩写的 Least Action World Model，面试时应先报论文全名避免混淆。

10 · DREAMZERO

DreamZero：联合视频—动作 WAM 的代表

WHAT CHANGED

从 VLM backbone 转向 video diffusion backbone

基于预训练视频生成模型，将未来视频与机器人动作在共享生成系统中联合建模；视频提供密集的物理变化表示。

WHY IT MATTERS

从重复模仿转向多样视频学习

论文强调从异构、多本体、非重复轨迹和人类视频中吸收 motion prior，再通过 action channel grounding 到机器人控制。

RUNTIME

闭环而非一次梦完整任务

按 action chunk 生成并执行，重新接收真实观测，用真实帧替代继续依赖幻觉的历史，减少长视频误差累积。

ENGINEERING

大模型实时化是核心难点

论文通过模型与系统优化让 14B 视频扩散模型达到 7Hz 闭环控制；这个结果体现了 WAM 的潜力，也暴露其部署成本。

与 LaWAM 对比

DreamZero 保留像素/视频级联合生成，表达直观但计算重；LaWAM 将未来压到冻结视觉 feature 中，一次预测 latent subgoal，再用 Action DiT 生成动作，目标是牺牲像素可视性换取低延迟。

12 · DATA & PRETRAINING

ALIGN TIME

按物理时间对齐

不同数据集控制频率不同。future horizon 应表示统一的秒数 τ，而不是都取“第16帧”；否则 latent action 混合不同运动跨度。

ALIGN VIEW

区分相机与物体运动

手持/头戴视频包含强 ego motion，world model 可能把相机变化当对象 dynamics，需要多视角、稳定化或显式相机状态。

ALIGN ACTION

动作语义比 shape 更重要

关节位置、末端增量、速度和夹爪状态不能只 padding 到同一维；必须建立 embodiment-aware adapter 与可执行约束。

14 · TACTILE WAM

触觉让“未来世界”包含真实接触

TACTILE AS INPUT

当前触觉条件动作

像 AT-VLA 一样把接触状态、触觉图像或短时窗口注入策略；它提升反馈反应，但不一定预测未来触觉。

TACTILE AS FUTURE

预测将发生的接触

对候选 action chunk 预测未来接触、形变、滑移或触觉 latent，再用预测结果指导动作选择和重规划，才是更典型 tactile WAM。

方法未来预测怎样用于动作与你的关联
Dream-Tac未来视觉 + 触觉 dynamics + actioncontact-gated 融合与 contact-aware attention从“触觉输入”进一步走到“触觉未来建模”
HiTac-WAMcontact state → 3D deformation → slip risk候选 chunk 排序；预测—观测偏差触发纠错对应触觉状态分层、滑移与在线重规划
QTac 可拓展方向未来在手数量分布 / 接触变化在执行重抓前预测数量变化与失败风险把 CountNet 从当前估计升级为 action-conditioned foresight
触觉 WAM 的难点

触觉高度依赖传感器材料、安装位置、预载、标定和采样率，跨设备 video prior 很难直接迁移。必须报告触觉预测的校准误差、缺帧策略和时间延迟，不能只看最终成功率。

18 · INTERVIEW Q&A

十个高频问题

Q1：WAM 的严格定义是什么？

没有唯一实现，但必须把未来世界建模与可执行动作建立学习接口。回答应给出未来表示、factorization、训练目标和推理路径，而不只是“会预测视频”。

Q2：WAM 为什么可能比 VLA 泛化更好？

视频预训练提供时序与运动先验，future objective 监督对象交互和状态变化，也能使用无动作标签视频。但优势取决于数据、动作 grounding 和评测扰动，不能普遍保证。

Q3：为什么生成未来能帮助生成动作？

未来状态描述任务需要达到的局部结果，IDM/action expert 再求实现该转移的动作；它把“动作标签记忆”转成“目标变化 + 如何实现”的分解。

Q4：WAM 必须 test-time imagination 吗？

不必须。显式视频 WAM 会生成；LaWAM 只生成 latent subgoal；Fast-WAM 仅在训练期做 video co-training，推理直接输出动作。

Q5：LaWAM 为什么要 latent action？

它从无动作视频的当前—未来变化中提取紧凑 transition code，使 LaWM 能学习 z 条件下的未来 feature，也为第二阶段 policy prior 提供蒸馏目标。

Q6：LaWAM 怎样避免 train–test mismatch？

训练期 posterior z 依赖真实未来；第二阶段通过 distillation 训练只看当前观测和语言的 policy prior，并用 predicted subgoal 训练动作头，减少部署时分布切换。

Q7：如何证明动作真的用了 world prediction？

做 future removal/swap、GT-vs-predicted future、world loss on/off、gradient/attention intervention，并检查动作与任务成功率是否因未来变化而因果改变。

Q8：为什么 pixel future 慢？

高维多帧 token 与多步扩散都昂贵，而且大量容量用于背景纹理。latent future 通过压缩和单步预测降低成本，但失去直观可视性。

Q9：WAM 与 RTC 的关系？

WAM 解决动作生成是否获得动态 foresight；RTC 解决慢模型如何不停顿地闭环执行。大型 WAM 尤其需要异步生成、队列阈值与前缀续写。

Q10：触觉怎样加入 WAM？

不仅把当前 tactile token 拼入条件，还可预测 action-conditioned future contact/deformation/slip，用于候选动作排序、风险评估和预测—观测偏差触发重规划。
