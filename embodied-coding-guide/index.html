02 · PRACTICE LOOP

每道题练四遍

“会解释”和“能手写”是两种能力。训练时需要主动移除提示。

ROUND 01看答案理解

逐行跟踪张量尺寸，弄清每个算子的目的。

ROUND 02关答案默写

只保留函数签名和输入输出约束。

ROUND 03边写边讲

模拟面试，先说思路、复杂度和边界情况。

ROUND 04制造错误测试

主动检查 mask、device、dtype、detach 和维度。

03 · UNIVERSAL CHECKLIST

写完代码先检查这些

多数现场手撕失分并不是公式不会，而是接口、尺寸或梯度处理不完整。

SHAPE

尺寸是否闭合

先在注释里写输入输出 shape，特别检查 transpose、reshape 和广播。

NUMERICS

数值是否稳定

softmax 前减最大值、log 前 clamp，方差和标准差加 epsilon。

GRADIENT

梯度流向是否正确

target 计算通常放进 torch.no_grad()；重参数化保留采样梯度。

DEVICE

设备与类型一致

新建 tensor 时继承输入的 device 和 dtype，避免 CPU/GPU 混用。

EDGE CASE

边界条件完整

考虑空输入、全 mask、序列长度为 1、终止状态和不可达路径。

COMPLEXITY

复杂度讲得出来

至少能说明时间、空间复杂度，以及优化前后的主要瓶颈。

04 · 7-DAY PLAN

一周最小训练安排

D1Self / Cross Attention

先写单头，逐行说清 QKᵀ、缩放、mask、softmax、加权求和。

D2Multi-Head + PE

反复练习 reshape/transpose；独立默写 sin/cos 位置编码。

D3KV Cache + Loss

区分训练与自回归推理；手写稳定 CE、MSE、Flow Matching。

D4Action Chunk

实现滑窗取数、动作队列和 Temporal Ensemble。

D5DQN / Double DQN

写清 gather、done mask、no_grad 和 target network。

D6SAC + 重参数化

掌握 tanh-squashed Gaussian 的采样、log_prob 修正和 actor loss。

D7算法题模拟

随机抽 3 题，每题 25 分钟，完整讲解复杂度与边界情况。
